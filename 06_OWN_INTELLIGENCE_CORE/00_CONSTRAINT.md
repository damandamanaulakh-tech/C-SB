```
NO EXTERNAL COMMERCIAL LLM API FOR CORE INTELLIGENCE
```

- local model weights stored inside the repository or an offline model store
- local inference runtime
- Sourceborn-native reasoning engine that does not call out

Forbidden for core:

- OpenAI / Anthropic / Google / xAI / any commercial completion endpoint as the permanent brain

The long-term objective is an own intelligence architecture with:

- proprietary Sourceborn corpus
- proprietary reasoning architecture
- proprietary graph
- proprietary nodes
- proprietary memory
- proprietary verification
- proprietary examples
- proprietary learning structure
- optional own neural language/model layer later

Do not prematurely force Sourceborn into a conventional transformer/LLM architecture.
Evaluate architecture according to Sourceborn requirements.
