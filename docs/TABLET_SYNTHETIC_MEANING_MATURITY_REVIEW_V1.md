# Tablet Synthetic Meaning Maturity Review V1

Status: `GROWING_PHASE_EVIDENCE_REVIEW`

This document evaluates the maturity of the current synthetic tablet meaning bank. It does **not** promote any synthetic meaning to a verified translation.

---

# 1. Maturity scale

```text
M0 — Synthetic seed
Interesting combination, but no meaningful source/object support yet.

M1 — Structurally grounded synthetic
Visible structure supports asking the question, but the semantic leap remains large.

M2 — Domain-plausible hypothesis
The proposed function exists as a real class of historical/inscription behavior, but is not demonstrated for this object.

M3 — Object-linked evidence hypothesis
Multiple independent facts about this object/image/context converge on the hypothesis.

M4 — Textually/source anchored
Actual signs/reading/order/grammar or equivalent source-level structure materially support the reading.

M5 — Mature interpretation
M4 + provenance + comparative evidence + counter-cases + falsifier survival + low proof debt.
```

Maturity is **not** probability.
