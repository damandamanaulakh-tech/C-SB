# Source Sovereignty Intake V1

Status: Phase-2 active controlled testing.

## Decision

Sourceborn adopts the useful part of the reviewed Purity Filter as an intake/governance contract, not as a replacement for the Universal Sequence.

```text
RAW INPUT
  ↓
POINT ZERO / RAW SOURCE LOCK
  ↓
SOURCE SOVEREIGNTY INTAKE
  ├─ preserve exact source
  ├─ preserve authorship/provenance
  ├─ separate source assertion from world truth
  ├─ generate Pattern / Intent / Category / Definition / Key Note candidates
  ├─ tag evidence and epistemic status
  └─ allow OPEN / HALT / child Sequence when unresolved
  ↓
UNIVERSAL SEQUENCE
  ↓
MICRO DECOMPOSITION / RUBRICS / PARAMETERS / RELATIONS
  ↓
NODES / ENGINES / MEMORY / DOUBT / R-F-R
  ↓
USER REVIEW
```

## What is adopted

1. **Raw-source sovereignty.** The original expression is preserved as immutable provenance.
2. **Point Zero.** Analysis must remain traceable to original conditions/source.
3. **Open mystery.** Unknown or incomplete material may generate a new bounded Sequence instead of being filled silently.
4. **Lexical compression as a machine idea.** Words may compress many states/relations; expansion must remain source- and context-aware.
5. **Extraction packet.** Raw Source → Pattern Candidate → Intent Candidate → Category Candidate → Definition Candidate → Key Note Candidate.
6. **Verification before promotion.** Fluent or deep interpretation is not accepted knowledge merely because it is coherent.

## Critical correction: source truth vs world truth

`RAW SOURCE = SOURCE TRUTH` means the system can prove what the source said and who/what supplied it.

It does **not** mean every proposition in that source is objective external reality.

```text
SOURCE ASSERTION
  ≠
OBSERVED WORLD FACT
  ≠
INFERENCE
  ≠
SYNTHETIC HYPOTHESIS
  ≠
APPROVED REUSABLE RULE
```

## Deep generation, conservative promotion

Sourceborn may generate aggressively inside Interpretation Space:

- alternative meanings,
- intent and emotion candidates,
- hidden-mechanism candidates,
- counterfactuals,
- pattern candidates,
- unresolved mystery branches.

Promotion is conservative. Reusable knowledge requires evidence linkage, epistemic status, scope/exceptions, counterexample or falsifier review, R-F-R/verification where applicable, and authorized human approval.

`NO EVIDENCE` may permit generation. It does not permit validation.

## Derivative-source rule

A polished rewrite, compiled archive, taxonomy, summary, definition, or model-generated synthesis is a **derivative representation**.

It must retain parent-source lineage and cannot be counted as independent corroboration of the parent.

```text
RAW SOURCE A
   ↓ derives
SUMMARY A1
   ↓ derives
FRAMEWORK A2

A + A1 + A2
does not equal
three independent sources
```

## Purity-filter scope

When performing ideological or conceptual extraction, budget/timeline/project-status/structural logistics may be excluded from that **view** so they do not pollute the conceptual extraction.

They are not deleted. Source custody preserves them separately.

## Candidate, not fact

The reviewed archive often supplied emotional intent labels, historical-purpose claims, social generalizations, causal business claims, and philosophical definitions. Sourceborn may retain these as candidate interpretations, but not silently promote them.

Examples:

```text
"protective / unyielding"
→ inferred emotion candidate

"MBA caused scaling"
→ causal hypothesis

"faith/trust/belief have one universal domain each"
→ project lexical proposal

"this historical text was designed for X"
→ historical-purpose hypothesis

"men/women are X"
→ scoped social hypothesis requiring evidence/counterexamples
```

## Machine handoff

Primary machine contract:

- `machine/runtime/SOURCE_SOVEREIGNTY_INTAKE_V1.json`

The Sentence Micro-Sequence runtime remains the execution path. Source Sovereignty supplies its Point-Zero intake packet; it does not create a parallel execution grammar.

## Promotion ladder

```text
RAW SOURCE
→ SOURCE-LOCKED OBSERVATION
→ REVIEWABLE EXTRACTION CANDIDATES
→ UNIVERSAL SEQUENCE / MICRO-SEQUENCE
→ EVIDENCE + RUBRICS + RELATIONS
→ INTERPRETATION SPACE
→ DOUBT / COUNTEREXAMPLE / R-F-R
→ USER REVIEW
→ APPROVED VERSIONED WRITE-BACK
→ REUSABLE PATTERN / RUBRIC CANDIDATE
```

The original source is never overwritten by the approved interpretation.
