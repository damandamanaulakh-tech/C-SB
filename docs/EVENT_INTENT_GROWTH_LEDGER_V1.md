## Five count layers

1. **Occurrence** — Event/example processed and preserved; may increment automatically.
2. **Activation** — existing IDs activated as candidates; frequency is not truth.
3. **Candidate support** — live intent/pattern signature receives a contribution; contradictions stay attached.
4. **Validated support** — increases only after required review/evidence acceptance.
5. **Canonical** — new approved IDs/patterns/rubrics require explicit promotion and applicable R-F-R.

`EXAMPLE COUNT != PARAMETER COUNT`, and `ACTIVATION COUNT != VALIDATED SUPPORT != CANONICAL TRUTH`.
