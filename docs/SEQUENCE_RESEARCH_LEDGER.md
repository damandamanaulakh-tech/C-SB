# Sequence Research Ledger — Phase-1 Closure

This ledger preserves the conceptual progression so future generated documents do not flatten the research history into the latest diagram.

## Baseline
The first baseline described Sequence with Position, Predecessor, State, Context, Availability, Trigger, Rule, Transition, Result, Dependency, Direction, Branch, Loop, Memory, Feedback, Interruption, Repair, Reversal, Compression, Expansion, Parallelism, Synchronization, Selection, Termination and Re-entry.

## Hunger falsification
Hunger showed that a visible need begins late. Earth/environment, food formation, qualification/testing, use, processing and inherited memory can all predate the eater's present hunger. Cooking/preservation/logistics can be separate Sequences created from earlier closed results. Memory prevents rebuilding the whole path from zero.

## Gravity test
Gravity broke the agent/stake middle of the early graph. It forced:
- no mandatory Requirement,
- coupling instead of intake,
- encounter instead of acquisition,
- conditioning instead of food-specific preparation,
- physical inheritance,
- physical/path memory without a rememberer,
- NOT_APPLICABLE as a legitimate closure/status,
- scope that can follow a relation/phenomenon rather than an agent.

## Pyramid test
Pyramids showed:
- Requirement can belong to another system,
- a represented future can causally precede target existence,
- design/selection/testing may be real but owned/performed by the human/project Sequence,
- borrowed operation is a relation, not merely a dot status,
- physical persistence does not imply intrinsic stake or self-action.

## Dot-vs-path review
The overlay dots are useful for Node Truth but not Path Truth. A real runtime needs connected typed edges showing divergence, bypass, borrowed ownership, convergence and closure.

## Closure / re-sequencing
A failed attempt never loops in place. Each attempt is a new Sequence with a unique ID, its own contract, result and Closure Packet. A parent may remain OPEN/SUSPENDED at a local barrier while required Sub-Sequences execute. Closed Sequences never reopen.

## Threshold
Threshold is an edge primitive distinct from trigger. Trigger = something happened/arrived. Threshold = condition that must evaluate true before the transition is permitted. Recheck conditions are explicit.

## Entity outcome
Sequence completion is not entity death. The Sequence may close successfully while the followed entity terminates, persists, changes, degrades, repairs, splits, merges or becomes incorporated.

## Mahabharata modelling lens
Used as a structural narrative test, not a historical/theological assertion. It contributed:
- seed before carrier,
- local/rider character Sequences under a larger global/coordinating Sequence,
- actor-view / knowledge distribution,
- future-action commitments/promises,
- latent consequences and downstream-critical small events,
- priority/arbitration and bounded Exception Contracts,
- rule inertia,
- convergence windows and multi-scale/era closure,
- observer/writer Sequence,
- narrative memory and law/guidance formation from closed cases.

## Human overlay
The Human at node N can be changed before entering N+1. Execution, learning and development run at different timescales. Native Human 10 Segments / 80 Containers / 2,560 parameters remain an independent registry. Sequence bindings are additive.
