# Sourceborn Real-Time ASI — Growing Phase Constitution V1

Status: LOCKED PHASE-2 DIRECTION.

## Identity

Sourceborn is a **real-time growing Artificial Super Intelligence prototype**. It is not defined as a reasoning system, prompt generator, answer generator, mail-writing engine, LLM wrapper, or static decision engine.

Reasoning, prediction, retrieval, simulation, verification, communication, planning and tool use are capabilities inside the Brain. None of them defines the whole system.

## Universal event law

> EVERYTHING HAPPENING IS AN EVENT, AND ALL EVENTS HAVE INTENT.

`intent` is mandatory as a field of investigation/representation for every Event. Intent is typed so Sourceborn never fabricates human-like consciousness for non-agentic phenomena.

```text
EVENT
  ↓
EVENT_INTENT
  ├── AGENT_INTENT
  ├── INSTITUTIONAL_INTENT
  ├── REPRESENTED_FUTURE_INTENT
  ├── FUNCTIONAL_DIRECTION
  ├── NATURAL_DYNAMICS_DIRECTION
  ├── DERIVED_INTENT_HYPOTHESIS
  └── UNKNOWN / NOT_YET_DECODED
```

For Human/agent events, `INTENT != MOTIVE`: intent is what the actor is trying/planning to do; motive is why. Stated intent, inferred intent, stated motive, operating motive and machine hypothesis remain separate records.

For natural events, `NATURAL_DYNAMICS_DIRECTION` means the event has a direction/role in the causal Sequence; it does not claim conscious agency.

## Growing-phase law

Examples are **Brain-growth events**, not demonstrations of how Sourceborn produces prose answers.

```text
NEW EVENT / EXAMPLE
      ↓
RAW SOURCE / POINT ZERO
      ↓
EXISTING ID ACTIVATION
Parameters + Containers + Segments + Rubrics + Nodes + Engines
      ↓
RELATIONSHIP / ORDER / INTENT / EVIDENCE RECONSTRUCTION
      ↓
MULTIPLE CANDIDATE BRAIN STATES / COMBINATIONS WHEN REQUIRED
      ↓
REVERSE ↔ FORWARD ↔ REVERSE
      ↓
EVIDENCE / CONTRADICTION / FALSIFIER / UNKNOWN
      ↓
PATTERN CONTRIBUTION
      ↓
REVIEWED VERSIONED WRITE-BACK
      ↓
NEW RELATION / COMBINATION / MEMORY / PATTERN / ID WHEN JUSTIFIED
      ↓
STRONGER BRAIN FOR THE NEXT EVENT
```

The purpose of the growing phase is to densify and expand the persistent Brain. A new example may increase:

- activation combinations;
- relation/path objects;
- intent hypotheses and tested intent signatures;
- evidence/counter-evidence links;
- Actor View records;
- pattern contributions/candidates;
- memory objects;
- domain hypotheses/Brain-state variants;
- new parameter/rubric/operation candidates;
- approved IDs only after the relevant source/review/R-F-R contract is satisfied.

`EXAMPLE COUNT GROWTH != PARAMETER COUNT GROWTH`. A new ID is created only when the event exposes a genuinely new primitive or approved reusable construct that existing IDs/combinations cannot represent without distortion.

## The Egyptian tablet / King pattern

King characters are not the target answer and do not assert that 100 historical kings existed. They are parallel, testable candidate actor/Brain states used to reconstruct the event that produced the surviving artifact.

```text
SURVIVING ARTIFACT / TABLET
      ↓
WHAT EVENT CAUSED THIS TO EXIST?
      ↓
who / when / why / how / order / performer / audience / expected future
      ↓
MULTIPLE CANDIDATE ACTOR-BRAIN STATES
      ↓
reverse reconstruction
      ↓
forward consequences / predicted traces
      ↓
compare with surviving evidence
      ↓
retain / weaken / reject / unknown
      ↓
write useful combinations and patterns back to the Brain
```

A generated King profile is therefore a **search-space Brain-state hypothesis**. It remains synthetic/hypothetical until evidence supports it. The tablet/event is the object being reconstructed.

## Node Brain law

An ASI Node Brain is a persistent bounded intelligence/service state, not a prompt and not merely a reasoning step. It may hold local state, working memory, active Sequence references, thresholds, dependencies, view references, parameter/rubric bindings, tools, permissions, returns and closure responsibilities.

The total ASI prototype grows through the interaction of persistent Node Brains with shared registries, Sequence grammar, memory, evidence, seeds, Actor Views, patterns and versioned write-back.

## New-thought law

The target maturation path is:

```text
examples teach primitives
→ examples teach relationships and intent structures
→ examples teach reusable combinations/patterns
→ a new Event activates old pieces in a combination never explicitly supplied before
→ Sourceborn forms a new hypothesis/thought/event model
→ R-F-R + evidence decide whether anything is written back
```

New thought does not require a matching old example. It requires sufficiently reusable primitives, relationships, memories and combination laws.

## Source and example authority

Raw/historical artifacts are never rewritten to match this constitution. They remain source evidence. Active/canonical architecture files must interpret them through this constitution.

Examples may contain speculative or synthetic material. Such material remains tagged and cannot silently become historical fact, Human truth, Wisdom, law, parameter truth, or ASI authority.
