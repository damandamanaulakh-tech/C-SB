## Core layer law

```text
SB-ASI-P0001..P2560 = NATIVE HUMAN PARAMETER BANK

Human Parameter != Rubric
Human Parameter != ASI Node
Human Parameter != Engine
Human Parameter != Element
Human Parameter != Sub-Parameter

```

The 2,560 Human records live at the Parameter layer. `CON-001..080` organize them. `SEG-01..10` organize the Containers. Rubrics interrogate/classify activated parameters. User edits create versioned interpretation/pattern/sub-parameter objects rather than silently rewriting native Human parameter identity.

## Important semantic separation

The native Human parameter bank is vocabulary/state-capability structure. A Rubric is an orthogonal question asked of activated objects or paths. A Human/ASI Node is a bounded runtime evaluator/service. An Engine is a bounded processor. A Pattern is a cross-Sequence reconstruction. A Sub-Parameter or Element can be proposed additively where evidence supports a finer split, but it is not allowed to overwrite the identity of `SB-ASI-P0001..P2560`.

## Runtime interpretation

```text
2,560 Human Parameters
        = Human vocabulary/state-capability bank

80 Containers
        = organization of that bank

10 Segments
        = coarse Human domains

52 Universal Rubrics
        = dimensions used to interrogate objects/paths

Node Brains
        = bounded evaluators/services

Engines
        = bounded processing mechanisms

Memory
        = retained/retrievable evidence and path dependence

Patterns
        = cross-Sequence candidate generalizations

User review
        = explicit scoped interpretation/pattern correction
```

The architecture therefore does not turn the 2,560 into 2,560 independent brains. It makes them addressable Human state/capability vocabulary that can be selectively activated inside a Sequence, interrogated by Rubrics, evaluated by bounded Nodes and Engines, compared through Memory, assembled into interpretations, and learned only through explicit versioned write-back.
